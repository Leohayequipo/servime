## ========================================
## 🆘 PROBLEMAS COMUNES
## ========================================

### ERROR 500:
1. Revisar logs: tail -f ~/servime/storage/logs/laravel.log
2. Verificar permisos: chmod -R 755 storage bootstrap/cache
3. Regenerar caches: php artisan cache:clear && php artisan config:cache

### BASE DE DATOS NO CONECTA:
1. Verificar .env tiene DB_HOST=localhost
2. Verificar nombre de BD en hPanel
3. Probar conexión: php artisan migrate:status

### CSS/JS NO CARGAN:
1. Verificar index.php apunta a ../servime/
2. Copiar public: cp -r ~/servime/public/* ~/public_html/
3. Verificar .htaccess en public_html

### IMÁGENES NO SE VEN:
1. Recrear symlink: php artisan storage:link
2. Verificar permisos: chmod -R 755 ~/servime/storage/app/public
3. Verificar ruta en .env: FILESYSTEM_DISK=local

### "NO APPLICATION ENCRYPTION KEY":
1. Generar key: cd ~/servime && php artisan key:generate
2. Verificar .env tiene APP_KEY con valor
