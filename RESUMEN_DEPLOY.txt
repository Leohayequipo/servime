╔══════════════════════════════════════════════════════════════════════════╗
║                     PROBLEMAS COMUNES Y SOLUCIONES                       ║
╚══════════════════════════════════════════════════════════════════════════╝

❌ ERROR 500:
   → Ver logs: tail -f ~/servime/storage/logs/laravel.log
   → Verificar permisos: chmod -R 755 storage bootstrap/cache
   → Limpiar cachés: php artisan cache:clear

❌ BASE DE DATOS NO CONECTA:
   → Verificar .env tiene DB_HOST=localhost
   → Verificar credenciales en hPanel
   → Probar: php artisan migrate:status

❌ CSS/JS NO CARGAN:
   → Verificar index.php apunta a ../servime/
   → Copiar public: cp -r ~/servime/public/* ~/public_html/
   → Verificar .htaccess en public_html

❌ IMÁGENES NO SE VEN:
   → Recrear symlink: php artisan storage:link
   → Verificar permisos: chmod -R 755 ~/servime/storage/app/public

❌ "NO APPLICATION ENCRYPTION KEY":
   → Generar key: php artisan key:generate
   → Verificar .env tiene APP_KEY
